## Reading order

New to the package: [../README.md](../README.md), then [components.md](components.md) for the API of the component you are about to use.

Changing the code: [architecture.md](architecture.md), then [../AGENTS.md](../AGENTS.md) for the traps and the exact commands.

Changing a colour or a theme: [tokens.md](tokens.md), then [../DESIGN.md](../DESIGN.md) for the rules the tokens have to satisfy.
