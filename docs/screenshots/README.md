# Screenshots

The documents reference one image: [../preview.png](../preview.png), a 1600x1125 capture of the gallery at the current release, used at the top of the [README](../../README.md).

New screenshots belong in this directory and are referenced by relative path, for example `![The modal](docs/screenshots/modal.png)` from the root README. The house-style checker verifies that every image reference points at a file, so a renamed or deleted image fails the build instead of leaving an empty box.
